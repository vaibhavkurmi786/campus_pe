# CampusPe Landing Page — Next.js

Responsive landing-page recreation based on the supplied CampusPe screenshot.

## Requirements
- Node.js 18.17+ (Node 20 LTS recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Production build
```bash
npm run build
npm start
```

## Included
- Next.js App Router and JavaScript
- Reusable section, card, CTA, navigation and logo components
- Responsive layouts for desktop, tablet and mobile
- Accessible focus states, hover/active feedback, mobile menu
- Working anchor navigation, role-card CTAs, app showcase carousel controls,
  resume upload interaction, and contact form feedback
- Reduced-motion support

## Notes
This is a front-end assignment implementation. Authentication, job listings, resume storage,
and real contact submission require CampusPe APIs/backend credentials; demo actions provide
local UI feedback and do not claim to submit data to CampusPe.

## Deploy
Import this folder/repository into Vercel, select Next.js, and deploy. No environment variables
are required for the demo.
